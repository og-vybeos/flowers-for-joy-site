# uploads/

Drop new photos, logos or videos here (on GitHub: **Add file → Upload files**),
then open an issue asking `@claude` to place them, for example:

> @claude Please use uploads/ren.jpg as Ren Hogue's team photo.

Claude resizes and renames each file, moves it to the right folder, updates the
site, and removes it from here. You can also place files yourself by following
README.md, in which case this folder isn't needed.
